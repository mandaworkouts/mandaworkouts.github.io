Ordering rules

The big one

  • 🏃 Never two running days back to back. Long Run, Threshold and Compromised are the three that drain you — spread them 2–3 days apart

Rest days

  • 😴 Always rest the day after Compromised — no running on wrecked legs
  • 💪 That same rest day sets up HYROX day fresh for heavy sleds
  • 📏 Keep your two rest days ~3 days apart, not bunched

Gym

  • 🔥 Threshold sits fine the day after Lower — never the day before HYROX day
  • 🦵 Lower can sit next to Compromised: its conditioning is ski/row/bike, so it isn't adding running load

A layout that works

  • Long Run → Lower → Compromised → Rest → HYROX & Upper → Threshold → Rest
